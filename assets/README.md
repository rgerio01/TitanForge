# Assets

Esta pasta deve conter os seguintes arquivos:

## Imagens Necessárias

1. **icon.ico** (256x256px ou maior)
   - Ícone do aplicativo para Windows
   - Formato: .ico
   - Usado no executável e na bandeja do sistema

2. **vortex-logo.png** (recomendado: 512x512px)
   - Logo do Vortex exibida na tela de login
   - Formato: .png com fundo transparente
   - Cores: Roxo (#8B5CF6) e gradientes

3. **background.jpg** (1920x1080px ou maior)
   - Background opcional para telas
   - Formato: .jpg ou .png
   - Tema: Dark/Futurista

## Como Adicionar

1. Coloque os arquivos nesta pasta
2. Certifique-se de que os nomes correspondem exatamente aos listados acima
3. Execute `npm run build` novamente se já tiver buildado o projeto

## Dicas de Design

- Use cores consistentes com o tema Vortex (roxo/violeta)
- Mantenha o design moderno e minimalista
- Para o ícone, considere usar ferramentas como:
  - [IconGenerator](https://www.icongenerator.com/)
  - [RealFaviconGenerator](https://realfavicongenerator.net/)

## Recursos Gratuitos

- [Unsplash](https://unsplash.com/) - Imagens de alta qualidade
- [Flaticon](https://www.flaticon.com/) - Ícones gratuitos
- [Freepik](https://www.freepik.com/) - Vetores e designs
